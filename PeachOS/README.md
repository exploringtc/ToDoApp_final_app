# Todo App

A simple todo list that runs on PeachOS.

Commands:
- add <task>
- list
- remove <id>
- help
- exit

Build:
./build.sh

Run:
qemu-system-i386 -hda PeachOS/bin/os.bin

Then type todo to start.
